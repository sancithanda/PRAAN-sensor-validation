# PRAAN – Sensor Placement Validation

This repository contains the experimental data and analysis
used to determine suitable sensor positions for the PRAAN
AI-powered Personal Health Companion Jacket.

## Sensors Evaluated

1. MPU6050 / BMA400 – Fall and activity detection
2. MAX30102 – Heart rate and SpO₂ monitoring
3. Chest Sound Sensor – Respiratory monitoring

## Experimental Objective

To compare different sensor positions based on:

- Signal quality
- Signal stability
- Motion artefacts
- Physiological proximity
- Suitability for integration into a wearable jacket

## Selected Positions

| Sensor | Selected Position |
|---|---|
| MPU6050 / BMA400 | Waist / Lower torso |
| MAX30102 | Left chest |
| Chest Sound Sensor | Upper chest / Sternum |

## Experimental Results

The raw measurements, processing methodology,
plots and comparison results are provided in the
respective folders.

## Application

The validated positions are used in the proposed
PRAAN wearable health-monitoring jacket.
